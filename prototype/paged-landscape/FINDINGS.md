# 検証結果 — 表ごとに用紙を横向きにできるか

実施: 2026-09-21 / 対象: [テーマ設計案 §6.2](../../design/theme.md)
環境: Chromium（Playwright 同梱）/ Paged.js

## 結論

**できる。表ごとに選べる。** ただし素直な方法では動かず、**向きごとに別パスで組版して PDF を自前で綴じる**必要がある。

## 素直な方法は動かなかった

CSS の名前付きページで指定するのが本来の書き方である。

```css
@page           { size: A4 portrait;  margin: 20mm; }
@page landscape { size: A4 landscape; margin: 15mm; }
.landscape      { page: landscape; }
```

結果は**全ページが A4 縦のまま**だった。

```
p1: 794x1123 縦
p2: 794x1123 縦
p3: 794x1123 縦   ← 横向きにしたかった表
p4: 794x1123 縦   ← 同上
p5: 794x1123 縦
```

### 名前付きページは認識されている

DOM を調べると、対象ページには正しくクラスが付いていた。

```
pagedjs_page pagedjs_right_page pagedjs_named_page pagedjs_landscape_page pagedjs_landscape_first_page
```

つまり **Paged.js は名前付きページを認識しているが、`size` だけは反映しない**。
Paged.js はページ寸法を文書全体で 1 つ持つ構造になっており、**ページごとに用紙サイズを変えられない**。

## 動く方法 — 向きごとに別パスで組版する

向きの違う区間をそれぞれ独立した組版として走らせ、出てきたページを順に綴じる。

```
=== 縦向きの組版 ===
  縦 p1: 794x1123 縦
  縦 p2: 794x1123 縦
=== 横向きの組版（表だけ別パス） ===
  横 p1: 1123x794 横   ヘッダ行:あり
  横 p2: 1123x794 横   ヘッダ行:なし
```

**それぞれのパスでは用紙サイズが正しく適用される。** 12 列の項目定義表も横向き A4 に収まった
（`split-landscape.png`）。

### これが成立するのは、PDF を自前で書くから

ブラウザの印刷機能に PDF 生成を任せていたら、**1 回の印刷で混在させるしかなく、この方法は取れなかった**。
[PDF を自前で書く決定](../../design/pdf-engine.md)が、ここで効いている。

ページ番号も[こちらで採番する](../../design/reference-syntax.md)ため、**パスをまたいでも連番を維持できる**。
ヘッダ・フッタも自分で描くので、向きが変わっても体裁を揃えられる。

### 利用者から見える記法は変わらない

```markdown
@import "auth-design/screen-items.table" {#tbl-items page="landscape"}
```

実装が別パスになるだけで、**指定の仕方は [テーマ設計案 §6.2](../../design/theme.md) のまま**でよい。

## 副次的な確認 — 表のヘッダ行は繰り返されない

横向きパスの 2 ページ目に**ヘッダ行が無い**（`hasHeaderRow: false`、画像でも確認）。
[テーマ設計案 §6.7](../../design/theme.md) で挙げた Paged.js の弱点が、実測でも再現した。

**設計書として体裁が成立しないため、対処が必須**である。

## 残る課題

1. **表のページ分割とヘッダ行の繰り返し**（上記）— 依然として実装時の最優先課題
2. **パス数の増加** — 縦・横が交互に現れる文書ではパスが増え、処理時間に影響する。
   連続する同一向きの要素はまとめて 1 パスにする
3. **二段階処理になる** — 目次や相互参照のページ番号は、**全パスの組版が終わるまで確定しない**。
   組版 → ページ番号確定 → 番号を埋めて再描画、という順序が要る

## 再現手順

```bash
npm install
node run.mjs          # 名前付きページでは向きが変わらないことの確認
node inspect.mjs      # 名前付きページのクラスが付いていることの確認
node run-split.mjs    # 別パス方式（動く方法）
```
